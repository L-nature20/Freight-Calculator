快速开始

本系统用于物流运费的试算与核对。按照以下 5 步顺序操作即可完成运费试算：

基础配置 合同与费率 交货单导入 零担审批 运费试算

点击左侧目录可快速跳转到对应章节。

1. 基础配置

在进行任何试算之前，需要先完成三项基础配置。进入 基础配置 标签页操作。

① 泡货体积重量折算系数

  • 默认值 3.5 m³/吨，即 1 吨货物占 3.5 立方米空间时视为"泡货"。
  • 当交货单体积÷重量 > 系数时，系统按 体积÷系数 计算"体积重量"作为计费重量。
  • 根据实际物流标准调整，修改后保存立即生效。

② 整车唯一标识

  • 选择用于将交货单归组为同一"车次"的字段（可多选，如"车牌号"、"拼车单号"等）。
  • 选中字段的值用 "-" 连接后作为唯一标识，相同标识的交货单归为同一车次。
  • 正确配置此项是车次级坎级计价的前提。

坎级区间

  • 定义重量分段（如 0-5吨、5-10吨、10吨以上），每个坎级有对应的单价。
  • 坎级必须 连续覆盖：无间隙（上一级上限 = 下一级下限）、无重叠。
  • 点击 校验 按钮可检查当前坎级配置是否有问题。
坎级配置错误将导致试算异常，请务必在校验通过后再进行试算。
2. 合同与费率

合同是运费试算的核心数据源，每条合同关联一组费率。进入 合同管理 标签页操作。

合同创建与导入

  • 新增：手动填写合同编码、名称、承运商、有效期等信息。
  • 导入：下载模板，填写后批量导入。支持 Excel (.xlsx) 格式。
  • 合同状态生命周期：草稿 → 生效 → 失效，也可标记为 作废。
  • 只有"生效"状态的合同才会参与试算匹配。

费率导入

  • 选中合同后，在右侧"费率详情"区域导入费率数据。
  • 费率按 线路 + 货物类型 + 运输方式 匹配交货单。
  • 每条费率包含多个坎级的单价（坎级1单价、坎级2单价…），以及 末端装卸费。
  • 路线代码由系统自动生成（装运点+运输区域组合），无需手动填写。
  • 税率填写小数形式（如 0.09 表示 9%），不能超过 1。
合同检索支持按合同编码、合同名称、承运商名称/编码进行模糊搜索。
3. 交货单导入

交货单是试算的输入数据，来源于 SAP 系统导出。进入 交货单管理 标签页操作。

模板字段说明

字段名说明
交货单号SAP 交货单编号，唯一标识
装运点 / 装运点描述发货地点编码及名称
运输区域 / 运输区域描述目的地编码及名称
总重量（吨）/ 总体积（m³）本交货单的重量和体积
拼车单号 / 运单号物流调度编号
发货过账日期SAP 过账日期，用于日期范围筛选
车牌号运输车辆车牌
销售组织 / 组织名称发货方组织信息
承运商名称 / 承运商编码承运物流公司，用于匹配合同
送达方名称 / 送达方编码收货方信息
货物类型 / 运输方式货物分类及运输方式，用于匹配费率

导入与去重

  • 下载模板填写后，点击"导入"按钮上传 Excel 文件。
  • 如果交货单号已存在，系统弹窗询问：跳过（保留原数据）或 覆盖（用新数据替换）。
  • 支持批量选择后删除不需要的记录。
4. 零担审批

零担（LTL）指一车装载多个交货单的运输方式。零担审批记录用于将运费分摊到各个交货单。进入 零担审批 标签页操作。

操作步骤

  • 新增：填写零担类型（支线/干线）、车序号、交货单号、审批月份（YYYYMM 格式）。
  • 导入：下载模板批量导入零担审批数据。
  • 系统根据零担审批记录关联交货单号，在试算时自动计算各交货单应分摊的车次运费。

查询与筛选

  • 支持按交货单号、零担车次、零担类型（支线/干线）、审批月份进行筛选。
  • 支持批量选择后删除。
零担审批数据必须在试算前完成录入，否则相关交货单将无法正确计算分摊运费。
5. 运费试算

所有基础数据准备完毕后，即可进行运费试算。进入 运费试算 标签页操作。

查询条件

  • 交货单号 / 运单号 / 拼车单号：精确匹配。
  • 发货过账日期：选择起止日期范围，默认最近一个月。
  • 承运商：支持模糊搜索；承运商编码 / 合同编码：精确匹配。
  • 结果状态：筛选"已匹配"或"无法匹配"的试算结果。

试算结果

  • 试算结果包含 51 列详细数据，涵盖交货单信息、车次分组、坎级匹配、运费计算等。
  • 自定义列：点击"自定义列"按钮，可拖拽调整列顺序、固定左侧/右侧、隐藏不需要的列。
  • 排序：点击表头可按该列排序。
  • 翻页：支持切换每页显示条数（20/50/100/200）。
  • 导出：将全部试算结果导出为 Excel 文件。

异常标记说明

异常标记含义
承运商无合同该承运商在系统中没有对应的合同记录
合同已过期承运商有合同，但在发货日期时合同已失效
线路无费率合同中未找到匹配的线路+货物类型+运输方式组合
货物类型无费率合同中未找到该货物类型对应的费率
超出坎级范围车次总重量超出所有坎级区间的上限
落档无数据无法确定落档坎级，通常是坎级配置不连续
异常标记会以 红色斜体 显示在试算结果表格中，悬停可查看详细说明。
