# 运费试算工具

## 快速启动

```bash
# 1. 安装依赖（首次使用）
pip install -r requirements.txt

# 2. 启动应用
python run.py
```

启动后自动打开浏览器，访问地址：http://127.0.0.1:5000

---

## 功能模块

| 模块 | 说明 |
|---|---|
| **运费试算** | 按查询条件执行试算，查看/导出50列结果 |
| **交货单管理** | 导入/新增/编辑/删除交货单数据 |
| **零担审批** | 导入/新增零担审批记录 |
| **合同管理** | 合同CRUD、费率管理、状态管理 |
| **基础配置** | 泡货系数（默认3.5）、坎级区间配置 |
| **帮助** | 操作指引，覆盖完整业务流程 |

---

## 数据导入

- 各模块提供"模板下载"按钮，下载标准 .xlsx 模板
- 交货单、零担审批、合同均支持 Excel 批量导入
- 合同费率需在合同详情页单独导入

---

## 计算逻辑

10步流程：拼车分组 → 车次汇总 → 按方判定 → 计费重量 → 零担判定 → 费率匹配 → 坎级落档 → 运费计算 → 交货单分摊 → 装卸费

**关键公式**：
- 体积重量 = 总体积 ÷ 泡货系数（默认3.5）
- 按方判定：车次体积重量 > 车次总重量 → 符合
- 整车落档：取非零坎级单价最小值对应坎级
- 零担落档：计费重量匹配全局坎级区间
- 适用运费 = MIN(预估运费, 上一坎级最低运费)

## 合同状态

- 启动时自动检查并更新状态（草稿→生效、生效→失效）
- 每天凌晨自动执行定时任务
- 支持手动"置为生效"、"置为失效"、"置为作废"

## 异常处理

| 场景 | 运费字段显示 |
|---|---|
| 承运商无合同 | 承运商无合同 |
| 合同已过期 | 合同已过期 |
| 线路无费率 | 线路无费率 |
| 货物类型无费率 | 货物类型无费率 |
| 超出坎级范围 | 超出坎级范围 |

仅运费相关9个字段显示标记，其他字段正常显示。
